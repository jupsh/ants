A per-ant time-shift null (cross-ant timing broken) reproduces 0.134 of B018's 0.198 periphery − core contrast in C
(share 0.68 [0.48, 0.86]): a periphery ant is nearly always moving, a core ant mostly still. Null-corrected, ants passing
through the periphery together still co-move (Δ 0.116 vs core 0.053). With zones fixed by 4-h mean position, periphery
pairs exist in only 3 colonies, so no zone contrast is readable; core-based ants: Δ 0.034 [0.030, 0.039]. The null also
removes colony-wide synchrony, so Δ does not separate local coupling from a shared driver. Synchrony cause: open.
